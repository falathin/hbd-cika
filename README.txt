JESSYCA BIRTHDAY SITE — QUICK SETUP

1. Open index.html in a browser, or deploy this folder to Netlify / GitHub Pages.
2. Put your music file at: assets/your-song.mp3
   The code already has a sample <source> path. Replace it if you use a different filename.
3. Add your four photos as:
   assets/photo-1.jpg
   assets/photo-2.jpg
   assets/photo-3.jpg
   assets/photo-4.jpg
   JPG or WebP is fine; if you use WebP, update each src in index.html.
4. The WhatsApp button opens +62 857-8145-7014 with the draft:
   "aku sudah liat web nya....."
5. To change the draft, edit the text after ?text= in the WhatsApp URL and URL-encode spaces (%20).

Notes:
- Audio playback starts only after the visitor presses Yes because browsers block autoplay with sound.
- The site uses Google Fonts when online, but falls back to system fonts if offline.
- The fireworks use a capped canvas particle count and a lower frame rate to keep the page light on phones.
